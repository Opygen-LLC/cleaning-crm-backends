# Required regression matrix and evidence boundaries

A passing native fixture executes production exports with explicit I/O adapters; it does not establish real database isolation, DNS, TLS, deployment topology or browser behavior. The full release commands retain the project's existing Vitest and renderer suites. See `VALIDATION.json` for the checks actually executed while building this patch.
